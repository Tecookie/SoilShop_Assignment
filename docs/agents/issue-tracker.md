# Issue tracker: Local Markdown

Issues and specs live as Markdown under `.scratch/`.

- One feature per directory: `.scratch/<feature-slug>/`.
- Feature specification: `.scratch/<feature-slug>/spec.md`.
- One file per implementation ticket: `.scratch/<feature-slug>/issues/<NN>-<slug>.md`.
- Record ticket state as a `Status:` line near the top.
- Append discussion under `## Comments`.
- Publishing to the issue tracker means writing a local file; no remote publication.

The triage skill is not configured. Do not create external labels.
