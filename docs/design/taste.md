# Visual direction

Quiet enterprise operations UI. Preserve the stockroom typography, spacing,
plain CSS and existing accent. Tables and labeled forms take priority over cards,
decorative illustrations or animation. Keep actions usable on narrow screens.

## 14 November 2026 refresh

Use forest green (#17362e) for navigation, green (#24735e) for primary actions,
warm neutral (#f5f6f3) for the workspace and white for working surfaces.
Continue using system fonts and quiet borders. Shared SVG outline icons replace
the mixed Unicode symbols; no UI or icon-library dependency was added.
