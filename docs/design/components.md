# Components

Reuse shared/components Field, Notice, Empty and Pagination and existing panel,
toolbar, table-wrap and form-grid styles. SearchSelect queries paginated API data,
keeps the current selection visible and announces lookup errors. Workflows must
show stock versions, review reasons and job status using text, not only color.

## 14 November 2026 additions

- `Icon`: shared decorative SVG outline icons; controls retain text or accessible names.
- Mobile navigation: explicit open/close controls, backdrop, keyboard trap and Escape.
- Login: password visibility toggle retains native labels and autocomplete.
- Notice/Empty: shared symbols supplement text and existing alert/status semantics.
- Pagination: visible item range and total; existing 20-item page contract retained.
- `danger`: distinguishes delete/cancel confirmations from ordinary form actions.
- Dashboard: Today/7-day/30-day controls, pressed state, legend and zero-data labels.
