# Advice must explain supplied facts

The shop cannot assume complete or independently verified growing-media data, so catalogue entry allows unknown values and advisory eligibility requires a recorded source/reviewer. Extend the existing stateless gRPC host with deterministic positive-match ranking and explanations rather than adding an LLM service; metadata can be reviewed and the scoring version changed without pretending the system certifies plant suitability. No match produces an explicit lack-of-information result.
